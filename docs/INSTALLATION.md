# Installation Guide for OneClickAPI

Follow the steps below to install the **OneClickAPI** plugin for **IntelliJ IDEA**.

##  Prerequisites

Before you begin the installation, make sure you meet the following prerequisites:

- **IntelliJ IDEA** (version 231.9000 or higher)
- **Spring Boot** project setup

---

##  Installation Methods

You can install **OneClickAPI** either from the **IntelliJ Plugin Marketplace** or via **manual installation**.

### **From IntelliJ Plugin Marketplace**

1. Open **IntelliJ IDEA**.
2. Navigate to **Settings**:
    - On **Windows/Linux**: Go to `File > Settings`.
    - On **macOS**: Go to `IntelliJ IDEA > Preferences`.
3. In the **Settings/Preferences** window, select **Plugins** from the left-hand sidebar.
4. In the **Marketplace** tab, type **"OneClickAPI"** into the search bar.
5. Click **Install** to install the plugin.
6. Once the installation is complete, **restart IntelliJ IDEA** to activate the plugin.

---

### **Manual Installation**

1. Download the latest **OneClickAPI** release `.zip` file from the [Releases](#) page.
2. Open **IntelliJ IDEA** and navigate to **Settings**:
    - On **Windows/Linux**: Go to `File > Settings`.
    - On **macOS**: Go to `IntelliJ IDEA > Preferences`.
3. In the **Settings/Preferences** window, select **Plugins** from the left-hand sidebar.
4. Click on the **gear icon** in the top right corner and select **"Install Plugin from Disk"**.
5. Choose the downloaded `.zip` file and click **OK** to install the plugin.
6. **Restart IntelliJ IDEA** to complete the installation and activate the plugin.

---

##  After Installation

Once installed, you will be able to use **OneClickAPI** in your **Spring Boot** projects.

- **Right-click** on a `@Entity` or POJO class in the **Edit** view of your project.
- Select **`Generate > Generate API`** from the context menu.
- Follow the on-screen prompts to configure and generate APIs.

Alternatively, you can **select multiple classes** at once. To do this:
1. Highlight the classes.
2. **Right-click** and choose **`New > Generate API`** to generate APIs for all selected classes at once.

---

This guide will help you easily install and start using the **OneClickAPI** plugin. 
Enjoy automating your API development!
